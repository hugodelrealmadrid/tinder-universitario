## Política de privacidad

LIGO es una aplicación de citas y conexiones para estudiantes universitarios mayores de 18 años. El responsable del proyecto es Hugo García Salazar. Para consultas sobre privacidad, escribí a hugodelrealmadrid@gmail.com.

Al crear una cuenta, LIGO usa tu correo para autenticarte y verificar la dirección. También trata tu nombre, fecha de nacimiento, afiliación universitaria declarada, sede, carrera, intereses y preferencias para crear y mostrar tu perfil y ayudarte a encontrar personas compatibles. Según cómo uses el servicio, LIGO guarda tus fotos de perfil, likes, matches, bloqueos, reportes, historias y los mensajes, fotografías y notas de voz que compartís en conversaciones. El chat y las historias se limitan a las personas autorizadas según el funcionamiento de la aplicación.

La fotografía del carnet se usa para revisar la acreditación universitaria. Se almacena de forma privada y se consulta mediante el flujo de verificación autorizado. El carnet y el correo de la cuenta no forman parte del perfil público. Los administradores autorizados pueden consultar datos de perfil y fotos para tareas de gestión. Las acciones administrativas pertinentes quedan registradas. Los reportes se usan para revisar posibles infracciones.

LIGO usa Firebase Authentication para las cuentas, Cloud Firestore para los registros, Cloud Storage para los archivos y Cloud Run para operaciones protegidas. Los avisos internos se consultan en la aplicación. Las notificaciones push externas están desactivadas en esta versión.

Para consultar, corregir o solicitar la eliminación de tus datos, escribí al correo de contacto. Evitá adjuntar contraseñas, códigos, documentos de identidad o carnets al correo inicial.

## Condiciones de uso

Para usar LIGO debés tener al menos 18 años. Para acceder a las funciones de citas, debés acreditar que sos estudiante universitario mediante el flujo de verificación de la aplicación. Registrá información propia y compartí solo fotografías y otros contenidos que tengas derecho a publicar.

Respetá a las demás personas. Se prohíben el acoso, las amenazas, la suplantación, el uso de carnets ajenos y la difusión de contenido privado sin autorización. Usá las opciones de bloqueo y reporte si corresponde. El equipo autorizado puede revisar reportes, rechazar verificaciones o suspender cuentas de acuerdo con los controles de la aplicación.

Para consultas sobre la aplicación o una decisión administrativa, escribí a hugodelrealmadrid@gmail.com. No envíes tu contraseña ni códigos de acceso.

## Solicitud de eliminación de cuenta y datos

Podrás iniciar una solicitud desde LIGO cuando el flujo esté disponible o escribir a hugodelrealmadrid@gmail.com con el asunto «Eliminar mi cuenta de LIGO». Hugo García Salazar será el responsable de tramitarla. Para proteger tu cuenta, LIGO comprobará que sos su titular mediante una sesión autenticada recientemente o una confirmación segura enviada al correo asociado. Evitá enviar contraseñas, códigos de acceso o carnets por correo.

Al verificar la solicitud, LIGO eliminará o anonimizará tu perfil, fotografías, datos académicos y relaciones vinculadas a tu cuenta, según corresponda. En conversaciones compartidas se protegerá la información de las otras personas. La baja retirará o anonimizará la información atribuible a tu cuenta sin borrar indiscriminadamente las conversaciones. Si se conserva información por un reporte de seguridad, deberá haber una finalidad específica, acceso restringido y una fecha de revisión.

Los respaldos se guardarán cifrados y con acceso restringido. La baja se registrará con la mínima información necesaria para impedir que la cuenta o sus datos reaparezcan si se restaura una copia. La restauración se revisará antes de volver a servir datos.

## Plazos operativos propuestos

| Operación | Propuesta para aprobación |
| --- | --- |
| Acuse de recibo | Hasta 3 días hábiles |
| Retirar acceso y visibilidad pública | Hasta 2 días hábiles desde verificar la titularidad |
| Eliminar o anonimizar datos de sistemas activos | Hasta 30 días calendario desde verificar la titularidad |
| Reportes y evidencias conservados por una finalidad justificada | Revisión a los 90 días desde su resolución. Cualquier extensión requiere motivo, responsable y nueva fecha de revisión, o un mandato aplicable |
| Copias operativas cifradas | Rotación dentro de 90 días. Inventariar por separado los respaldos de recuperación previos y definir su vencimiento antes de prometer este límite |
| Registro mínimo para impedir reaparición tras una restauración | Hasta vencer la última copia que pueda contener los datos, con acceso restringido |

Estos plazos son decisiones operativas propuestas. Su publicación exige aprobarlas, implementarlas y verificarlas. Ante una orden vinculante, registrar alcance, motivo y vencimiento de la conservación excepcional.
